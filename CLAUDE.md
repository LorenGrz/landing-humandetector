# Contexto del proyecto

Landing estática de portfolio para **HumanDetector** (repo aparte,
`LorenGrz/HumanDetector`): una instalación satírica de "verificación de
humanidad" que pide gestos reales por cámara (MediaPipe) y casi nunca
aprueba. Este repo **no tiene lógica propia** — solo enlaza a la app real y
al repositorio. Next.js 16 con `output: 'export'`, deploy automático a
GitHub Pages en cada push a `master`
(https://lorengrz.github.io/landing-humandetector/).

Repo hermano del mismo patrón (landing estática + app aparte): también hay
`landing-booklibre`, `landing-frauddetector`, `landing-prioria`,
`landing-serverlessscanner`, `landing-studyquest`.
